State Pattern

Pattern where a client class holds onto a State interface which it can call methods on. Multiple ConcreteStates will then inherit from State in which the Concrete itself controls what the next state is.

class Client {
  State state;

  void next() {
    state.next(this);
  }

  void set(State state) {
    this.state = state;
  }
}

interface State {
  T method(U u);

  void next(Client client);
}

class ConcreteState implements State {
  T method(U u) { ... }

  void next(Client client) { ... }
}
