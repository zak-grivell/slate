def mat_mult_square(A, B):
  n = len(A)
  C = [[0] * n for _ in range(n)]
  
  for x in range(n):
    for y in range(n):
      C[x][y] = sum(A[x][o] * B[o][y] for o in range(n))

  return C

This is not very speedy
