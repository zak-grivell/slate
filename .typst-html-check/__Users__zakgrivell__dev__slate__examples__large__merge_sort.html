Merge Sort

Splits up the elements into two sections until singles then merge back together

Time Complexity:

The recursion forms a splitting tree and a combination tree which is with the merging being therefore it is overall

def merge(a, b):
  if not a:
    return b

  if not b:
    return a

  if a[0] <= b[0]:
    return [a[0]] + merge(a[1:], b)
  else:
    return [b[0]] + merge(a, b[1:])
  
def merge_sort(A):
  if len(A) < 2:
    return A
    
  mid = len(A) // 2

  return merge(merge_sort(A[:mid]), merge_sort(A[mid:]))
