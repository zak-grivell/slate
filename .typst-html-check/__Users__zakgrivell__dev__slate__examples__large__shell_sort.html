Shell Sort

Optimization of Insertion Sort. It has a gap property, initially len(A) // 2, and performs insertion sort on elements that are gap positions apart. It then halves the gap again; this repeats until the gap is one.

This means the array is already partially sorted, which is useful for insertion sort because it reduces long swap sequences.

Time Complexity: 

def shell_sort(A, gap=len(A)//2):
  if gap == 1:
    return insertion_sort(A)
  
  for x in range(0, len(A), gap+1):
    if A[x + gap] < A[gap]:
      A[x+gap], A[x] = A[x], A[x+gap]

  return shell_sort(A, gap//2)
