Requirement Gathering

Scope is what the application actually does and does not do.

A Prototype is a quickly made version of the application for presentation purposes

When asking questions to clients many types

  • Likert Scale (strongly agree to strongly disagree)
  • Categorical
  • True/False
  • Closed question
  • Open Ended

Interviews are a scale. At one end, structured interviews have a list of exact questions, which makes them easy to follow and compare but can lack depth because there are no follow-ups. At the other end, unstructured interviews have no set questions, which allows follow-ups for deeper understanding but needs a skilled interviewer and is hard to compare. Semi-structured interviews sit in the middle: there is a list of questions, but follow-ups are used to get deeper information.

A user story is used to inform developers about a feature, a bug, or another requirement. It helps developers understand the feature and the exact requirements needed.
