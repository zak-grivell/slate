Intro Sort

A combination algorithm that starts with Quick Sort and switches to Heap Sort if recursion gets too deep, preventing quick sort’s worst case.

def intro_sort(A):
  if recursion_depth > LIMIT:
    return heap_sort(A)

  k = get_partition()

  return quick_sort([x for x in A if x < k]) + [x for x in A if x == k] + quick_sort([x for x in A if x > k])
