Decorator

Pattern that allows dynamic layering of objects to add responsibilities without modifying the original component.

A component implements the Component interface with the methods available, whereas a decorator wraps another component which can be either a concrete component or another decorator.

Inheritance vs Composition

But does decorator break the prefer composition over inheritance principle? No, because the decorator is using composition to hold a reference to the component it is decorating, rather than inheriting from it. The decorator can be seen as a wrapper around the component, allowing for additional functionality to be added without modifying the original component.
